# 交付物与完成标准

> 适用阶段：搬运完成后、发布前。确认产出物完整、路径正确。

## 搬运验收标准

- [ ] 短文 MD 文件存在（`短文/{文章名}.md`）
- [ ] 截图 N 张（`短文/assets/{文章名}/slide-01.png` ~ `slide-NN.png`）
- [ ] 硬质量验收已通过（quality-checklist.md 5 项标准 PASS）
- [ ] 风格门已通过（六轴 ≥ 3 + 反模式全 PASS + 版式动效合规）
- [ ] 宏观结构已记录到任务日志（下次避免重复）
- [ ] HTML 源文件已保留（`html-ppt/examples/{deck名}/index.html`）

## 发布前检查清单

> 产出物验收门（莱兹手动执行发布前）逐项确认。

- [ ] 正文已清理 Markdown 格式（无 `**` `` ` `` `##` `- ` `*` `---`）
- [ ] 段落间保留空行（双换行 `\n\n`）
- [ ] 正文 ≤ 1280 字符（微信 API 限制）
- [ ] **末尾关注引导已添加**：`▒▒▒▒▒▒▒▒▒▒` → 关注语 → `▒▒▒▒▒▒▒▒▒▒`（逐行对照，缺一不可）
- [ ] **frontmatter tags 全部已转换为文末 `#标签` 格式（逐条对照，缺一不可）**
- [ ] 所有图片路径存在（`短文/assets/{文章名}/slide-*.png`）
- [ ] 标题 ≤ 32 字

## 引用规则

- 短文文末 `## 相关图片` 引用宽度统一为 `300`
- MD 语法：`![描述|300](assets/{文章名}/slide-NN.png)`
- 封面图放引用第一张，CTA 图放最后一张
