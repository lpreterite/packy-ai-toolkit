# 风格设计验收门禁（风格门）

> 由 wx-newspic-sop 步骤 4（硬质量 quality-checklist）之后、步骤 5（搬运引用）之前触发加载。硬质量保证"没坏"，风格门保证"好看"。

---

## 门禁位置

```
C0 前置确认 → C1 内容提炼 → 🔒内容门 → C1.5 设计决策
→ C2 HTML编写 → C3 渲染截图 → 🔒视觉门 → C4 硬质量quality-checklist
→ 🔒风格门（本文件）→ C5 搬运引用
```

**为什么风格门放在 quality-checklist 之后**：风格门的修复（调间距/换版式/去装饰）不影响文字完整性和溢出，但反过来，硬质量修复（改字号/拆页）会影响风格。先硬后软，避免重复验收。

**三道门禁各司其职**：
- 内容门：PPT 说了什么（读者问题有没有回答）
- 视觉门：PPT 说了的话在图上能不能看到
- 硬质量（quality-checklist）：截图有没有技术缺陷（截断/溢出/字体）
- 风格门（本文件）：PPT 好不好看（设计审美）

---

## 验收标准（三大板块，共 21 项）

### A. 七轴设计自评（7 项）

每套 PPT 在发出前，按 7 个维度自评 1-5 分。

| # | 维度 | 1 分（差） | 3 分（及格） | 5 分（好） | 你的评分 |
|---|------|-----------|-------------|-----------|---------|
| A1 | **哲学（Philosophy）** | 满屏装饰无理由 | 每元素有定位 | 每元素有叙事意义 | /5 |
| A2 | **层级（Hierarchy）** | 所有元素等大 | 有大小对比 | 信息流速明确引导视线 | /5 |
| A3 | **执行（Execution）** | 有溢出/错位/缺失 | 全部正常显示 | 比例精确、间距微调到位 | /5 |
| A4 | **具体（Specificity）** | 用 AI 套话/空数据 | 给真实数字/案例 | 数据来源明确可查 | /5 |
| A5 | **克制（Restraint）** | 每页都填满 | 有留白有呼吸 | 删除比增加更频繁 | /5 |
| A6 | **多样（Variety）** | 每篇 PPT 结构相同 | 同类有变化 | 跨文章也用不同宏观结构 | /5 |
| A7 | **配色纪律（Color Discipline）** | 强调色飘得到处都是 | 偶尔看到一两个但能接受 | 需要刻意找才发现哪些被强调 | /5 |

**判定规则**：
- 全部 ≥ 3 分 → ✅ 通过，进入板块 B
- 任意维度 ≤ 2 → ❌ 不通过，回退 C2 修改后重新自评

**自评要点**：
- A3（执行）：这里不是重查截断/溢出（那是 quality-checklist 的事），而是看整体视觉精致度——字号过渡是否自然、间距是否均匀和谐、元素对齐是否有呼吸感
- A5（克制）：核心原则来自 `guides/design-guide.md` 的"留白是贵的"——每页只讲一件事，不要在视觉上填满每一寸空间
- A6（多样）：核心原则来自 `guides/design-guide.md` 的"禁止连续两篇相同宏观结构"——检查当前 PPT 是否与上一篇短文 PPT 的宏观结构雷同
- A7（配色纪律）：检查强调色是否精准聚焦——每页至少找出 1 处可以去掉的多余强调色

---

### B. 反模式红线检查（10 项）

源自 Hallmark PPT 设计经验提炼的 10 条反模式。每条必须 PASS。

| # | 反模式 | 检查方法 | PASS/FAIL |
|---|--------|---------|-----------|
| B1 | **渐变标题** — 标题用 `background-clip: text` 加渐变颜色 | 检查 slide 内容页标题是否为纯色或字重变化（封面可例外） | / |
| B2 | **全居中对称** — 所有页面内容全居中对齐 | 至少 1 张内容页打破对称（左对齐/双栏/不对称布局） | / |
| B3 | **emoji 当图标** — 特性卡片用 emoji（🎨🔤📐）作核心视觉图标 | 检查有无 emoji 替代了本应由 SVG/icon 承担的视觉角色 | / |
| B4 | **同间距等距** — 每页 padding/间距完全一样，无松紧变化 | 不同页面应有松紧节奏差异，尤其是信息密度不同的页面 | / |
| B5 | **深色底发光阴影** — 深色背景上用发光 `box-shadow` 或 `text-shadow` | 用明度差/色相差代替阴影营造层次 | / |
| B6 | **同一宏观结构** — 当前 PPT 与上一篇短文 PPT 的宏观结构雷同 | 对照 `guides/design-guide.md` §宏观结构选择，确认未连续重复 | / |
| B7 | **虚构数据** — 出现非用户/非原文提供的指标数字 | 每个数字必须能在原始资料中找到来源 | / |
| B8 | **单元素独撑一页** — 一页只有一行大字没有支撑内容 | 大字页应有副标题/标签/装饰等至少 2 个辅助元素 | / |
| B9 | **颜色滥用** — 同一页强调色使用超过 2 处（kicker 标签、装饰线、标题高亮各算 1 处；页面底色/全背景渐变不算） | 逐页计数强调色出现位置，超过 2 处 → FAIL | / |
| B10 | **图标混搭** — 同一 deck 内出现多风格图标（写实 image / 扁平 SVG / emoji 混杂）；或技术类内容出现非必要图标 | 检查 deck 中所有图标节点，记录源类型；风格 > 1 种或技术类存在非必要图标 → FAIL | / |

**判定规则**：
- 全部 PASS → ✅ 通过，进入板块 C
- 任一 FAIL → ❌ 不通过，修改后重新过板块 A + B

**注意**：B8 是对 A5（克制）的补充——克制不等于空洞。一页可以只有一行大字（如章节切换页），但不能没有任何辅助元素（副标题、装饰线、emoji、标签等至少有一个）。

---

### C. 版式与动效校验（6 项）

核心原则来自 `guides/design-guide.md` 的版式选择表和动效选择策略。

| # | 检查项 | 通过条件 | PASS/FAIL |
|---|--------|---------|-----------|
| C1 | **版式多样性** | 相邻两页用了不同版式（从 `html-ppt/templates/single-page/` 中对照） | / |
| C2 | **动效克制** | 每页不超过 2 种动效（CSS 入场 + Canvas FX 总计） | / |
| C3 | **主题一致性** | 整份 deck 只用一个主题 CSS（`data-themes` 列表不算混搭） | / |
| C4 | **留白充足** | 每页有呼吸空间（padding ≥ 40px，水平内边距 ≥ 60px），没有被信息填满的页面 | / |
| C5 | **视觉节奏** | 叙事阶段完整且疏密有致，不出现连续 3 页以上同密度 | / |
| C6 | **信息密度控制** | 每页不超过 4 个独立信息模块（卡片/数据块/列表组），文字不填满所有留白 | / |

**判定规则**：
- ≥ 5 PASS → ✅ 通过
- ≤ 4 PASS → ❌ 不通过，修改后重新过全部门禁

**C5 视觉节奏的参考模式**：
```
封面（疏）→ 定位/概述（中）→ 痛点/问题（中密）→ 数据/亮点（密）→
方案/功能（中密）→ 案例/证明（中）→ 步骤/教程（密）→ CTA（疏）
```
节奏的核心：有疏有密，不要所有页面信息密度一致。

```
**B. 反模式红线**：B1 ✅ B2 ✅ B3 ⚠️（slide 5 用 emoji 作卡片图标，建议后续改 SVG）B4 ✅ B5 ✅ B6 ✅ B7 ✅ B8 ✅ B9 ✅ B10 ✅ → ✅ 全部 PASS

**C. 版式动效**：C1 ✅ C2 ✅ C3 ✅ C4 ✅ C5 ⚠️（slide 3-5 连续中密，可接受）C6 ✅ → ✅ 6/6 PASS

**判定**：✅ 通过
```

## ⚠️ 标记的处理规则

⚠️ 标记表示"当前可接受但值得关注"。处理规则：

| 场景 | 处理 |
|------|------|
| 单次出现 | 记录但不阻塞流程 |
| 同一套 PPT 出现 ≥ 3 次 | 建议修改后再发出 |
| 连续 2 套 PPT 同一项出现 | 提升为必改项，下次必须 PASS |
| 连续 3 套 PPT 同一项出现 | 固化为反模式红线（加入 B 板块） |

---

## 不通过时的回退策略

| 情况 | 回退目标 | 修复范围 |
|------|---------|---------|
| A（六轴自评）不通过 | C2 HTML 编写 | 调整布局/间距/元素层级/删减装饰 |
| B（反模式红线）不通过 | C2 HTML 编写 | 去掉渐变标题/打破对称/替换 emoji 图标/调整间距 |
| C（版式动效）不通过 | C1.5 设计决策 + C2 HTML 编写 | 重新选版式/删减动效/调整视觉密度 |

**回退后必须重新走完整流程**：修改 HTML → C3 重新渲染 → C4 硬质量 quality-checklist → 🔒风格门（本文件）。

**最多重试 3 轮**。3 轮后仍有不通过项，向队长汇报问题截图和已尝试的修复方案。

---

## 硬规则

| 规则 | 说明 |
|------|------|
| 门禁不可跳过 | 风格门是必经环节，不能因为"赶时间"或"内容简单"而跳过 |
| 必须在 quality-checklist 之后 | 硬质量过关后才过风格门，避免重复验收 |
| 不通过必回退 | 存在 ❌ 时必须回退修改，不能用 ⚠️ 或跳过替代 |
| 回退范围最小化 | 只涉及 HTML/CSS 修改 + 重新渲染，不涉及内容提炼 |
| 自评必须客观 | 六轴评分不能全部打 5 分，至少有 1 个维度打 3-4 分（没有完美设计） |
