# 视觉验收门禁（视觉门）

> 由 SKILL.md §二 步骤 3 之后、硬质量验收之前触发加载。「内容门」确认了"PPT 该说什么"，「视觉门」确认"说的话在图上能不能看到"。

---

## 执行时机

wx-newspic-sop 步骤 3（渲染截图）完成后、步骤 4（硬质量验收）之前。

## 执行流程

### Step A：读图验收

用 image 工具逐张读取截图，对照内容门阶段产出的「版面与内容对照表」，检查：

1. **可见性检查**：对照表中标注 ✅ 的验收问题，在图片上是否真的能看到对应内容？
2. **可读性检查**：图片上的文字是否清晰可读？有没有截断、溢出、过小？
3. **完整性检查**：对照表中标注 ⚠️ 的验收问题，图片上是否至少有提示性信息（哪怕不完整）？

### Step A2：布局与色彩纪律检查

对照"版面与内容对照表"和截图，逐条检查：

| # | 检查项 | 通过条件 | PASS/FAIL |
|---|--------|---------|-----------|
| L1 | **边距充足** | 内容区与 slide 边界间距 ≥ 60px（水平），无信息紧贴左右边界 | / |
| L2 | **信息密度** | 每页独立信息模块数 ≤ 4，无视觉拥挤感 | / |
| L3 | **配色克制** | 强调色使用 ≤ 2 处/页，且不用于正文文字 | / |
| L4 | **图标一致** | 所有图标来源风格一致，或无图标仅用边框 | / |
| L5 | **尺寸合规** | 截图分辨率是否为 1350×1800px（DPR=2），非 1620×2160 | / |

**判定规则**：5/5 PASS → 继续。任意 FAIL → ❌ 不通过，回退步骤 2。

### Step B：判定

- Step A（读图验收）和 Step A2（布局色彩）**两者都通过**才为最终通过。

Step A 判定：

| 判定结果 | 条件 | 处理 |
|---------|------|------|
| ✅ 通过 | 所有 ✅ 项在图片上可见且可读 | 进入 A2 检查 |
| ⚠️ 部分通过 | 个别 ✅ 项在图片上不完全可见 | 标注问题，让队长决定是否可接受 |
| ❌ 不通过 | 有 ✅ 项在图片上完全看不到 | **回退到步骤 2** |

Step A2 判定：

| 判定结果 | 条件 | 处理 |
|---------|------|------|
| ✅ 通过 | 5/5 PASS | 进入步骤 4（硬质量验收） |
| ❌ 不通过 | 任意 FAIL | **回退到步骤 2**：调整 HTML 布局/配色/图标，重新渲染 |

### 不通过时的回退策略

- 明确告知队长：哪张 slide 的哪个内容不可见、建议如何调整布局
- 回退涉及 HTML 修改 + 重新渲染

## 硬规则

| 规则 | 说明 |
|------|------|
| 门禁不可跳过 | 视觉门是必经环节，不能因为"赶时间"或"内容简单"而跳过 |
| 不通过必回退 | 存在 ❌ 时必须回退修改，不能用 ⚠️ 或跳过替代 |
| 回退范围最小化 | 视觉门回退只涉及 HTML 修改 + 重新渲染，不涉及内容提炼 |
