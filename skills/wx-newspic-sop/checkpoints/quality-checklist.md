# 截图硬质量验收清单

> 适用阶段：PPT 渲染后、视觉门通过后立即执行。每张截图按以下 5 项标准验收，全部 PASS 才能进入下一步。

## 验收标准

| # | 检查项 | 通过条件 | 失败示例 |
|---|--------|---------|---------|
| 1 | **文字完整** | 所有标题、正文、标签文字完整显示，无截断、无乱码、无缺失 | 标题被裁切只显示一半；标签文字消失 |
| 2 | **布局无溢出** | 内容不超出 slide 边界，四周（尤其右侧/底部）无裁切 | 右侧文字/贴纸被截断；底部内容超出 1080px |
| 3 | **布局无错位** | 元素对齐正确，无重叠、无偏移、间距均匀 | 两段文字重叠；卡片对齐不一致 |
| 4 | **字体正常** | 中英文字体正常渲染，无 fallback 宋体/楷体/默认 serif | 英文标题变成 Times New Roman；中文变成宋体 |
| 5 | **元素完整** | 所有图片、贴纸、装饰元素、图标完整显示 | 贴纸显示为 broken image；图标方块 |

**判定规则**：5/5 通过 → PASS。任意 1 项 FAIL → 修复后重新验收。

## 验收流程

### 步骤 1：MD5 去重

```bash
cd <output-dir>
md5 *.png | awk '{print $4}' | sort | uniq -d
```
有输出 → FAIL，排查渲染问题。无输出 → 进入步骤 2。

### 步骤 2：抽检

抽检首/中/尾三张，用 image tool 逐张检查 5 项标准。全部 PASS → 进入步骤 3。

### 步骤 3：全量检查（可选）

内容量大时对所有截图逐张验收。

## 失败回退

截图 FAIL → 修复 HTML/CSS → 重新渲染 → 重新验收。最多重试 3 轮。
