# Topic Engine 方法论

> 复刻自「圈外ai」选题 agent 的逆向分析。所有判断基于当前用户的 IP 定位，与示例中的圈圈本人无关。

## §1 IP 定位六件套（会话临时采集，不持久化）

每次会话开始时一次性问齐：

| # | 字段 | 说明 | 示例 |
|---|---|---|---|
| 1 | IP 身份 | 一句话：你是谁、做什么 | 圈圈，老板IP获客操盘手 |
| 2 | 核心主张 | 反复相信且被验证的那句判断，最好呈"大众 X / 我 Y"式 | AI 替你干活，但不能替你背书 |
| 3 | 目标人群 | 谁会为你的判断买单 | 有生意、想做 IP 获客的老板 |
| 4 | 差异化打法 | 你和同行的分叉点 | 用营销打法做 IP，不是网红打法 |
| 5 | 转化路径 | 内容 → 线索 → 成交的链路 | 评论区留行业 → 免费诊断 → 成交 |
| 6 | 主平台与内容形式 | 决定标题风格与留资动作 | 视频号口播 / 抖音短视频 / 公众号图文 |

**核心主张逼问三问**（用户给不出主张时用）：
① 你最常否定同行的哪个做法？② 你的客户成交前的最后一刻，买的到底是什么？③ 哪句话你的客户复述过最多遍？

## §2 素材类型（引用依据的两根柱子）

- **A 行业热点**：正在热榜/发酵中的事件。风险=时效，核实重点="最新进展与最新数据"
- **B 同行爆款拆解**：钩子已被市场验证的内容。风险=数据口径，核实重点="数据是否属实"

本引擎主入口是 A；用户给 B 时同样走三方向路由。

## §3 内容目的三分法 + 证据门槛（路由前必查）

每个方向归入前先过门槛，不满足必须显式写排除理由：

| 目的 | 职责 | 证据门槛 | 结尾动作 |
|---|---|---|---|
| 圈人群 | 借热点破圈拉新，让非粉丝第一次建立认知 | 有信息差或大众情绪接口，泛相关、够多人刷得到 | 开放提问 / 行动号召，不收线索 |
| 建信任 | 展示判断力，让已关注者敢找你 | 有亲历证据或独家判断撑得住（撑不住就是普通点评，反伤人设） | 不设钩子 |
| 搞线索 | 直接触发私信/评论留资 | 痛点具体到能对号入座 + 我的服务接得住 + 钩子有真实落地入口 | 留资引导 |

排除理由分两类并注明是哪类：
- **证据门槛不够**（撑不住）
- **策略考虑**（这期不该，如"先扩认知、不急转化"）

**三方向角度分工**（同一热点的天然分工）：
- 圈人群 = 事件本身 + 影响了谁
- 建信任 = 报道层二阶拆解（报道里没写的、被简化的、背后的生意）
- 搞线索 = 把事件落到读者自己身上，对号入座

## §4 选题五道筛（每条素材全部通过才立项）

1. **流量筛**：素材自带流量吗？（热榜在榜 / 正在发酵 / 已验证爆款数据）
2. **人群筛**：目标人群会刷到、会在意吗？
3. **空位筛**：主流内容都在讲什么大词？我回答的具体问题是不是没人讲？
4. **反差筛**：大众结论是什么？我的判断能不能相反或更深一层？
5. **主张筛**：能不能自然拐回核心主张？（拐不回的素材再火也放弃）

生成后在每条选题尾部输出逐筛 pass/fail 自检。

## §5 反差引擎（选题的灵魂）

动笔前先写这一行：**"大众结论是 X；我的判断是 Y。"**
写不出 Y，或 Y 换成任何人说都成立（没有用户的主张烙印），就换选题。

**换主语测试**：把 Y 里的主语换成任何同行账号，还成立 → 说明没有"我"，重写。

参考样式（来自金标准示例，学结构不抄观点）：
- 大众：AI 别碰内容 / 我：AI 替你干活，但不能替你背书
- 大众：粉丝数=账号价值 / 我：获客力才是价值，粉丝数只是结果
- 大众：AI 内容不能做了 / 我：倒下的全是工具人，站起来的该是生意人

## §6 留资引导三原则 + 钩子形态库

原则：
1. 动作门槛极低（把账号发来 / 评论区留下行业）
2. 钩子是"诊断"不是"卖课"
3. 诊断维度预设差异化（钩子本身在强化主张）

钩子形态库：
- **账号诊断型**：把账号发来，帮你判断 X
- **行业评论型**：评论区留下行业，帮你看 Y
- **关键词暗号型**：私信指定暗号，给初步判断

红线：钩子必须有确认过的落地入口和承诺（谁来接、接了给什么），没落地就不写。

## §7 证据等级

**自有客户数据（案例库） > 公开报道数据 > 定性判断。**

有高等级证据时不拿低等级凑；`~/.dsh/topic-engine/cases.md`（若存在）里的条目是最高等级，优先引用。

## §8 防翻车红线

1. 选题阶段可引用未核实信息，但必须在「信息补充建议」里显式标注核实项
2. 热点类必须标注"文案阶段按最新进展再核一遍"
3. 禁止编造案例数字；没有真实案例就写方法论，标注"待补真实案例"
4. 所有「判断依据」必须可辩护：流量在哪、人群是谁、空位是什么
5. 涉及本人观点/内幕口径的判断，需本人确认后才能进文案
6. 二阶拆解只拆报道的**事实性偏差**（标题设计、被省略的事实、数据口径），不揣测动机、不诛心

## §9 复盘协议

用户提出复盘时：读台账被毙条目 → 统计哪道筛最常拦人 / 哪类目的最常被毙 → 提出筛子校准建议 → 用户确认后更新本文档。

## §10 输出契约（每条选题严格按此字段结构）

```
选题 N：{{热点事件}}：{{反差式副标题}}
- 素材类型：
- 引用依据：① 事件事实 ② 与我的 IP 的关联/反差点
- 内容目的：
- 判断依据：（流量面 / 人群精准度 / 内容空位 / 反差点 / 线索开口 / 为何排除另外两个目的，逐条说清）
- 核心观点：（一句话金句化，必须含反差）
- 反差对照：大众：X / 我：Y
- 内容结构：（内容目的）匹配 XX型
- 结构匹配与展开：（按 structures.md 对应模板逐段写出每段要点）
- 五道筛自检：（逐筛 pass/fail，不通过的注明原因）
- 信息补充建议：（核实清单：待核实项 + 核实方式 + 状态）
```

证据等级标注：引用依据里的每条标 [自有数据]/[公开报道]/[定性判断]。
